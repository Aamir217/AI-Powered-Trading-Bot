# Project instructions for Claude

## Commit attribution

Do **not** add Claude/Anthropic attribution lines to git commits or pull
requests in this repository (no `Co-Authored-By: Claude ...`, no
`Claude-Session: ...`, no "Generated with Claude Code" footers).

Commits should credit the human author only, e.g.:

```
Co-Authored-By: Mohd Aamir <mohd23506@gmail.com>
```
